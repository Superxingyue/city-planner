# 架空城市规划设计器

一款轻量级的网页端城市规划设计工具，面向架空世界构建、Minecraft 城市规划等场景。

## 快速开始

直接用浏览器打开 `index.html` 即可使用。

## 功能概览

| 功能 | 说明 |
|------|------|
| 底图上传 | 支持卫星图、手绘草图、现有地图作为底图，可调节不透明度 |
| 道路绘制 | 贝塞尔曲线（自动平滑）、折线两种模式；高速/主干/次干/支路/匝道五级，多层套色渲染（蓝边+灰底+红虚线+绿隔离带） |
| 匝道 | 独立匝道工具，平滑曲线连接道路 |
| 路口自动处理 | 丁字路口自动截断多余部分，十字路口正常相交，红线交点显示绿色圆点 |
| 街区智能填充 | 点击被道路围合的街区内部，自动识别边界并填充用地分类，自动编号 |
| 街区拆分器 | 画贝塞尔曲线像剪刀一样拆开现有街区 |
| 片区划分 | 多边形、矩形两种手动模式；按 GB 50137-2011 用地分类高饱和平涂 |
| 标注 | 自定义文字标注，可调字号 |
| 比例尺校准 | 拖拽已知长度线段，输入实际米数，自动校准比例 |
| 图层管理 | 底图/水系/用地/路网/标注五层，可独立显隐 |
| 道路节点编辑 | 右键道路进入编辑模式：左键添加节点、右键删除节点、拖拽移动节点 |
| 右键菜单 | 街区/标注右键可快速更改属性、删除 |
| 撤销重做 | Ctrl+Z / Ctrl+Y，最多 80 步 |
| 工程保存 | 导出 JSON 工程文件，可随时加载继续编辑 |
| 一键成图 | 自动生成含图廓、图名、图例、指北针、比例尺的规划图 PNG |

## 核心操作

- **绘制道路**：选工具 → 左键逐个点击添加锚点 → 按 **Enter** 完成
- **编辑道路**：**右键**道路进入节点编辑 → 左键道路附近添加节点 → 右键节点删除 → 拖拽节点移动 → Enter 退出
- **填充街区**：选"填街区" → 选择用地分类 → 点击道路围合的区域内部
- **拆分街区**：选"拆街区" → 画一条穿过街区的贝塞尔曲线 → Enter 执行拆分
- **右键菜单**：街区/标注上右键可快速修改属性或删除

## 操作流程

1. **上传底图**（可选）：点击顶栏「底图」按钮上传图片，调节左侧不透明度
2. **校准比例**（可选）：选择「校准」工具，在底图上拖拽一条已知长度的线段，输入实际米数
3. **绘制路网**：选择「自由路」或「折线路」，在左侧选择道路等级，开始绘制
4. **划分片区**：选择「多边形」或「矩形区」，选择用地分类（如 R2 二类居住），绘制区域
5. **添加标注**：选择「标注」工具，设置文字后点击画布放置
6. **编辑调整**：切换「选择」工具，点击实体可修改属性、拖拽顶点
7. **导出成图**：点击顶栏「导出成图」，自动生成含图例/指北针/比例尺的 PNG

## 用地分类（GB 50137-2011）

- R 居住用地（黄）
- A 公共管理与公共服务（橙）
- B 商业服务业设施（红）
- M 工业用地（灰紫）
- W 物流仓储（深灰）
- S 道路与交通设施（浅灰）
- U 公用设施（棕）
- G 绿地与广场（绿）
- E 水域与其他（蓝）
- H 特殊用地（浅紫）
